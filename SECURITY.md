# Security Policy

## Reporting

Use GitHub's private vulnerability reporting on this repository (Security tab, Report a vulnerability). Do not open a public issue for security problems.

Include the version, steps to reproduce, and the impact you observed. You will get a reply within a week.

## Scope

In scope:

- Leaking profile data to a web page or any remote host.
- A web page reading stored answers or the profile through the content script.
- Filling or submitting a form without a user action.
- Bypasses of the output checks on model answers.

Out of scope: issues that require a compromised browser or operating system.

## Supported versions

Only the latest release receives fixes.
