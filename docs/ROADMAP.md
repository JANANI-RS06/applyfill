# Roadmap

Each milestone ships as a set of small commits with tests.

## M0 Foundation
- Project scaffold, strict TypeScript, build pipeline, CI.

## M1 Data layer
- Profile schema, validation, storage in IndexedDB, answer memory.

## M2 Field engine
- Field discovery including shadow DOM, label resolution, classification, value resolution.

## M3 Filling and verification
- Native setters, framework-safe events, selects, radios, checkboxes, custom dropdowns, read-back verification.

## M4 Multi-step and dynamic forms
- Mutation observation, step change detection, repeated sections.

## M5 Interface
- Options page with profile editor, popup, in-page chip.

## M6 Resume import
- PDF and DOCX text extraction, deterministic parser, review screen.

## M7 Local model
- WebLLM in the service worker, consent flow, validated answers, fallback.

## M8 Hardening
- Browser integration tests, fixtures for common form patterns, accessibility pass.

## M9 Release
- Documentation, packaging, privacy policy, store listing, v0.1.0 tag.

## After 0.1
- Model-assisted resume parsing, per-site fixes contributed as fixtures, more locales for dates and phone formats, Firefox build.
