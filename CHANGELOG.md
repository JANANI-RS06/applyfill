# Changelog

## 0.1.0

- Profile editor with personal details, employment, education, skills, preferences, and self-identification.
- Autofill for text, textarea, select, radio, checkbox, combobox, date, and file fields, including open shadow roots.
- Multi-step and dynamic form handling.
- Read-back verification with a per-field report.
- Answer memory and correction capture.
- PDF, DOCX, and text resume import.
- Optional local model through WebLLM with output validation.
